# Iris Flower Classification

## Introduction

This project focuses on classifying Iris flowers into three different species using a machine learning model. The classification is based on the measurements of sepal length, sepal width, petal length, and petal width.

## Dataset

The dataset contains four input features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The target variable consists of three flower species:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Machine Learning Model

Random Forest Classifier

## Project Workflow

1. Loaded the Iris dataset.
2. Selected the input features and target variable.
3. Split the dataset into training and testing sets.
4. Trained the Random Forest Classifier.
5. Predicted the species of test samples.
6. Evaluated the model using accuracy and classification report.

## Result

The model achieved an accuracy of **100%** on the test dataset and successfully classified all three Iris flower species.

## Conclusion

This project helped in understanding the basic workflow of a machine learning classification problem, including data preparation, model training, prediction, and performance evaluation.
