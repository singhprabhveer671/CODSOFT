# Titanic Survival Prediction

## Introduction

The main objective of this project is to predict whether a passenger survived the Titanic disaster using machine learning. The prediction is made based on passenger details such as age, gender, ticket class, fare, and family information.

## Dataset

The dataset contains information about Titanic passengers, including:

* Passenger Class
* Gender
* Age
* Fare
* Number of Siblings/Spouses
* Number of Parents/Children
* Port of Embarkation

The target column is **Survived**, where:

* 0 = Did Not Survive
* 1 = Survived

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Machine Learning Algorithm

Random Forest Classifier

## Project Workflow

* Loaded the Titanic dataset.
* Handled missing values in the dataset.
* Converted categorical data into numerical values.
* Selected important features for prediction.
* Split the dataset into training and testing sets.
* Trained the Random Forest model.
* Predicted passenger survival.
* Evaluated the model using accuracy and classification report.

## Result

The trained model was able to predict passenger survival with good accuracy. The performance was evaluated using accuracy score and classification metrics.

## Conclusion

This project provided practical experience in data preprocessing, feature selection, model training, and evaluation. It also helped in understanding how machine learning can be applied to solve real-world classification problems.
